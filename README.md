# RADIX Talent Match Platform

A multi-step, animated talent intelligence and skillset gap mapping platform.

## 🚀 Quick Start

### Backend (Flask API)
```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend (React + Vite)
```bash
cd frontend
npm install
npm run dev
```

For full details on the REST API endpoints and integration testing, please refer to [api_guide.md](api_guide.md).
